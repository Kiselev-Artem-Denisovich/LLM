# RAG-пайплайн по PDF и HTML с цитированием источников

Локальный поисково-ответный пайплайн (RAG — Retrieval-Augmented Generation):
индексирует PDF- и HTML-документы, находит релевантные фрагменты по запросу
и генерирует ответ через YandexGPT с обязательными ссылками на источники.

## Что делает

1. **Загрузка документов** из папки `C:\Данные_pdf`:
   - PDF — постранично, с извлечением оглавления (TOC), таблиц и заголовков по размеру шрифта.
   - HTML — секционно (h1–h4, p, li, table, dl, pre), таблицы превращаются в `|`-разделённые строки, код — в ```.
2. **Очистка текста**: склейка переносов по дефису, нормализация пробелов и пустых строк, удаление повторяющихся колонтитулов.
3. **Структурное разбиение на чанки** (`structure_aware_split`):
   - сначала режем по заголовкам `##` / `###`;
   - внутри секции — `RecursiveCharacterTextSplitter` (500 символов, overlap 50).
4. **Векторизация** моделью `sergeyzh/rubert-tiny-sts-v2` (HuggingFace) — работает офлайн.
5. **Хранение** в локальном Qdrant (`path=...`, без сервера).
6. **Поиск** top-k ближайших фрагментов с порогом косинусной близости (`score_threshold=0.7`).
7. **Генерация ответа** через Yandex AI Studio (`yandexgpt-lite`), temperature=0.1.
   Промпт требует: отвечать **только по источникам** и ставить ссылки `[1]`, `[2]`, … .
8. **Валидация цитат**: предупреждение, если модель сослалась на несуществующий номер.
